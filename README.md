# Student Performance Analytics System

## Project Overview
This project analyses student performance using Python, Pandas, and NumPy.

## Project Objective
The objective is to calculate student marks, averages, grades, and results and identify top performers.

## Technologies Used
- Python
- Pandas
- NumPy
- CSV Dataset
- Visual Studio Code

## Dataset
The dataset contains 20 students with the following information:
- Student_ID
- Name
- Maths
- Science
- English
- Attendance

## Features
- Calculate total marks for each student.
- Calculate average marks.
- Count subjects with marks of 50 or above.
- Assign grades.
- Determine Pass/Fail results.
- Identify the highest and lowest performers.
- Calculate subject-wise statistics.
- Handle missing marks.
- Save results to a CSV file.

## Grading Rules
- A+: 90 and above
- A: 80–89.99
- B: 70–79.99
- C: 60–69.99
- D: 50–59.99
- F: Below 50

A student passes if they score at least 50 marks in every subject.

## How to Run
1. Install Python.
2. Install the required libraries:

   pip install pandas numpy

3. Keep main.py and students.csv in the same folder.
4. Run the program:

   python main.py

5. The results will be saved in student_results.csv.
